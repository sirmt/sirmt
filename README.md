# Takudzwa Mupfure Portfolio

## Run locally

Install Node.js, then run:

```sh
npm install
npm run dev
```

Vite prints a local URL after the development server starts. Create a production build with `npm run build`.

## Personalize before publishing

- Add your real projects, education details, and specific tools or support experience when ready; the current copy avoids assuming details you have not provided.
- Replace the sample workspace image in `src/styles.css` with a photo you have permission to use, or a professional photo of yourself.

If Command Prompt says `npm` is not recognized after installing Node.js, refresh its PATH for the current window with:

```bat
set "PATH=C:\Program Files\nodejs;%PATH%"
```
